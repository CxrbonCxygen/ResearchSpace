# ResearchSpace · 个人科研空间

连接科研项目、训练实验、知识卡片和每日推进的私人科研工作台，提供网站和离线 Android APP。

## 功能

- 科研项目：研究问题、方法、数据集、同条件实验对比和历史记录。
- 训练可视化：逐 Step 曲线、完整评测、GPU 状态和 CSV 导出。不同生成长度分开比较，未完成评测不填准确率。
- 知识卡片：KaTeX 公式、数字与张量例子、参考来源和间隔复习。
- 每日推进：单次、每日、指定星期、日期区间；分类变化保留过去记录。
- 安卓离线：本机保存、联网合并、冲突选择；打开过的训练曲线可离线查看。

## 登录与数据

使用所有者设置的独立用户名和密码。站点入口可以公开，科研数据接口仍要求登录。首次部署由所有者通过 `/account/setup` 设置账号；不要把尚未初始化账号的新实例直接暴露给无关访客。密码使用随机盐和 PBKDF2，服务端仅保存密码摘要和会话摘要。账号与科研数据保存在部署环境的 D1，不包含在源码或 APK 中。

Android 会话通过 Android Keystore 加密保存，密码不会保存在手机上。项目、卡片和任务写入本机 IndexedDB，APP 运行时每 30 秒以及联网恢复、返回前台、手动同步时同步。关闭 APP 后的后台同步尚未实现。覆盖安装同签名新版会保留应用数据；卸载会删除未同步的本机内容，请先同步或导出。

## 训练数据

`/api/training` 提供登录后的实验和曲线读取；`/api/training/ingest` 接收限定实验的写入令牌。令牌不能读取工作空间。采集器可从已有日志补齐历史；源机器不能访问网站时，可通过电脑转发。SSH 账号、私钥和采集令牌不放进网站源码。

网站的训练页面位于 `/training`。Android 1.0.2 在 APP 内提供训练入口，联网后缓存查看过的曲线与评测，离线时明确显示缓存时间。离线数据不代表实验最新状态。

## 开发与验证

需要 Node.js >= 22.13，运行：

```sh
npm ci
npm test
npx tsc --noEmit
npm run dev
npm run build
```

`drizzle/` 包含数据库结构迁移。开发身份模拟仅用于本机回环地址，生产部署需要配置自己的身份和数据库。Sites 部署使用 `.openai/hosting.json`；为自己的站点配置独立项目标识与 D1 绑定，不复用他人的数据库。

Android 项目放在相邻的 `../android`。先构建离线前端：

```sh
node node_modules/vite/bin/vite.js build --config mobile/vite.config.ts
```

随后按 Android README 构建 APK。签名文件、环境配置、运行时数据和依赖目录均应保留在 Git 之外。当前测试覆盖分类历史、公式渲染、重复规则、离线合并、认证、真实项目更新和曲线离线缓存；构建测试不等同于所有手机型号的实机验证。
